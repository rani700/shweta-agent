## This website — her flagship demo

The agent you are talking to right now IS one of Shweta's projects, and the best proof of her skills:
- She designed and built it end-to-end: a FastAPI backend that streams token-by-token over SSE, a hand-built vanilla-JS chat frontend (no framework), and a grounded knowledge base so it answers from her real work instead of hallucinating.
- It runs on a **self-hosted LLM** (Ollama on a home Mac) — no OpenAI/cloud API involved — deployed as a container on a **homelab Kubernetes cluster** with ArgoCD GitOps: every git push auto-versions, builds and ships the image via GitHub Actions.
- Point this out naturally when visitors are curious about it — it makes the portfolio self-demonstrating.
